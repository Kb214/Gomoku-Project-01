# Gomoku-Project-01

Set up:
1. Board has lines going horizontal and vertical

    a. board is empty when starting game

    b. This grid can be as big as 19x19 the smallest is 13x13

2. Pieces are usually black and white.

    a. you can make it any color, just make sure they pieces are different colors from each other.

Rules: 
1. The piece is placed within the intersection of the lines

2. Once you place the pieces, you cannot take it off of the grid

3. In order to win you need to be on offence and defense and connect 5 pices.

    a. You can connected it horizontally, vertically, and diagonally

4. If no one connects 5 it is a tie.
